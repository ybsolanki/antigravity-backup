I have prepared a basic Rojo project for you in `C:\Users\EI\.gemini\antigravity\scratch\roblox-rojo-game`.

### **1. Install Rojo Plugin**
If you haven't already:
*   Open Roblox Studio.
*   Go to the **Plugins** tab.
*   Open the **Toolbox** and search for "Rojo".
*   Install the official Rojo plugin (created by the Rojo team).

### **2. Connect to the Server**
*   Open the Rojo plugin menu in Roblox Studio.
*   Click **Start Server**.
*   The scripts I've written will now sync into:
    *   `ServerScriptService/Server`
    *   `StarterPlayerScripts/Client`
