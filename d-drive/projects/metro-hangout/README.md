# Metro Hangout

A simple and clean social hangout space for Roblox.

## Getting Started

1.  **Rojo**: Use [Rojo](https://rojo.space/) to sync the `src` directory into Roblox Studio.
2.  **Scripts**:
    *   `src/server/init.server.lua`: Main entry point for server logic.
    *   `src/client/init.client.lua`: Main entry point for client logic.
    *   `src/client/AmbienceController.lua`: Handles the "Metro" lighting and atmosphere.
    *   `src/server/SocialService.lua`: Handles player data and social interactions.

## Features
- **Metro Ambience**: Preset lighting and post-processing effects.
- **Social Core**: Built-in player connection handling.
- **Rojo-Ready**: Professional development workflow.
